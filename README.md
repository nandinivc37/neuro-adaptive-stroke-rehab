# Neuro-Adaptive Closed-Loop System for Stroke Rehabilitation using Real-Time EEG and Computer Vision

> An AI-powered rehabilitation system that combines Brain-Computer Interfaces (BCI), Electroencephalography (EEG), Computer Vision, and Machine Learning to deliver personalized stroke rehabilitation through real-time neuro-adaptive feedback.

---

## Overview

Stroke rehabilitation traditionally relies on physical movement to evaluate patient progress. However, motor recovery depends heavily on cortical activation and neuroplasticity.

This project proposes a closed-loop rehabilitation system that simultaneously analyzes:

- 🧠 Neural Intent using EEG
- 🎥 Physical Movement using Computer Vision
- 🤖 Machine Learning-based adaptation

The system continuously adjusts rehabilitation exercises according to the patient's neural engagement and movement performance.

---

## Key Features

- Real-time EEG acquisition
- Motor intention detection
- MediaPipe Pose Estimation
- Neuro-Motor Congruence Score
- Adaptive rehabilitation engine
- Performance Accommodation Mechanism (PAM)
- Interactive clinician dashboard
